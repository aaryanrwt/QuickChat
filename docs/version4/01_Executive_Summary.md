# QuickChat V4: Executive Summary

QuickChat Version 4 marks a fundamental shift in the project's trajectory: becoming a 100% free, open-source, and community-driven terminal-native communication platform. V4 completely removes all previous commercial, enterprise, and closed-source restrictions. 

**Core Mission:**
To provide the ultimate, zero-configuration, secure, and extensible developer communication tool that lives entirely in the terminal, owned and maintained by its community.

**Key V4 Highlights:**
*   **Fully Open Source:** All previously gated features (SSO, advanced plugins, relay servers, audit logging) are now completely free and open-source under a permissive license.
*   **P2P First:** Built on a Rust networking stack using QUIC and the Noise Protocol for absolute privacy and end-to-end encryption.
*   **Decentralized Infrastructure:** Introduces self-hosted relay servers and DHT-based peer discovery, eliminating any reliance on central authorities.
*   **Community-Powered Extensibility:** A robust WASM plugin ecosystem available to all, without a premium marketplace.
*   **Developer-Centric:** Deep integration with CI/CD, local LLMs, live code pointers, and shared terminal sessions.

QuickChat V4 is not just an update; it is a commitment to the open-source ethos, ensuring that the best communication tools for developers remain accessible to every developer, everywhere.
