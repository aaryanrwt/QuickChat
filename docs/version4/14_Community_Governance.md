# QuickChat V4: Community Governance

V4 transitions QuickChat from a company-led project to a fully community-governed open-source initiative.

## 1. Open Governance Model
*   **Maintainers:** Core maintainers are elected based on merit and sustained contributions to the project, regardless of corporate affiliation.
*   **RFC Process:** All major architectural changes, new features, and protocol updates must go through a public Request for Comments (RFC) process on GitHub before implementation.
*   **Transparency:** All project management, roadmaps, and bug tracking are public. There are no private issue trackers or internal-only codebases.

## 2. Licensing
*   The entire QuickChat V4 ecosystem (Core, CLI, Relays, SDK) is licensed under permissive open-source licenses (MIT or Apache 2.0). 
*   There are no CLA (Contributor License Agreement) requirements that transfer copyright to a single corporate entity, ensuring the code remains forever free.

## 3. Decentralized Infrastructure Funding
*   Instead of charging for "Enterprise" features, the project relies on community donations (GitHub Sponsors, Open Collective) to fund official infrastructure (e.g., bootstrap nodes for the DHT, public plugin registry).
*   Companies are encouraged to host their own relay nodes and contribute code upstream.
