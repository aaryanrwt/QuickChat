# QuickChat V4: Feature List

QuickChat V4 includes all features from previous versions, with formerly paid/enterprise features redesigned as free, open-source capabilities.

## 1. Core Communication
*   **P2P Messaging:** Real-time text with Markdown and syntax highlighting.
*   **Secure File Transfer:** Drag-and-drop, high-speed transfer with Zstd compression.
*   **Rich Media in Terminal:** Sixel/Kitty image rendering.
*   **Presence & Status:** Typing indicators, read receipts, and custom statuses.

## 2. Developer Workflows
*   **Live Code Pointers:** Clickable references to specific files/lines in local editors.
*   **Terminal Sharing:** Read-only and interactive shared terminal sessions.
*   **CI/CD Hooks:** Native, open integrations for build/deployment notifications.
*   **Command Output Sharing:** Easily pipe `stdout`/`stderr` to chats.

## 3. Democratized "Community" Features (Now 100% Free)
*   **Self-Hosted Identity:** OpenID Connect (OIDC) and SAML support for teams who want to host their own identity providers, replacing the proprietary SSO.
*   **Community Relays:** Open-source relay server software for offline messaging and NAT traversal. Anyone can host a relay node.
*   **Audit & Compliance Tools:** Local, encrypted audit logging features available to all users and self-hosted team admins.
*   **Persistent Group Chats:** Decentralized storage consensus or self-hosted relays enable permanent rooms.

## 4. Extensibility & AI
*   **WASM Plugin Engine:** Full access to the plugin API.
*   **Local LLM Integration:** Built-in hooks for Ollama and other local models for code explanation and summarization, ensuring privacy.
