# QuickChat V4: Vision

**The Vision:** To be the ubiquitous, invisible, and infinitely extensible communication layer for the global developer community.

QuickChat V4 envisions a world where developers never have to leave their terminal or switch context to collaborate. We believe that communication tools for developers should be built like the best developer tools: fast, keyboard-centric, secure by default, and entirely open-source.

**Strategic Pillars:**
1.  **Terminal-Native Excellence:** The TUI is not a gimmick; it is the core experience. Every interaction must be faster and more intuitive than GUI alternatives.
2.  **Absolute Privacy:** Communication is a fundamental right. QuickChat ensures privacy through mandatory end-to-end encryption (Noise Protocol) and decentralized peer discovery (mDNS, DHT).
3.  **No Walled Gardens:** V4 dismantles all previous "Community" barriers. Features like SSO (now OpenID Connect for self-hosted instances), audit logging, and team management are democratized.
4.  **Infinite Extensibility:** The WASM plugin system allows the community to integrate QuickChat with any tool (GitHub, Jira, Docker, local AI) without needing core team approval.
5.  **Community Governance:** The roadmap and feature prioritization are driven by the community, for the community.
